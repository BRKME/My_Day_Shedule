# Утренние картинки

Кидай сюда файлы `.jpg` / `.jpeg` / `.png` / `.webp` — бот сам подхватит их
в утреннюю ротацию, править код НЕ нужно.

Как добавить: на GitHub открой эту папку → **Add file → Upload files** →
перетащи картинки → **Commit**. Со следующего утра они в пуле.

Выбор картинки — детерминированная ротация по дню года с перемешиванием
сидом года: повторов нет, пока не показаны все; каждый год порядок другой.
